Causality & Association in nD

A living research + practice project on causal science: literature review, self-evolving workflow (UCL), ground-truth reference world, interactive walkthrough, and real-data reproductions — all unit-tested against known truth.

🚀 Panel Demo 📓 Jupyter Notebook 💻 GitHub Repo

What is this?

📚

Literature Review

~140 cited references from Hume (1748) to the TARGET Statement (2025) — first principles, frameworks, identification, estimation, discovery, tools, and interdisciplinary bridges.

🔄

Universal Causal Loop

9-station self-evolving workflow: FRAME → ASSUME → IDENTIFY → DATA → FEATURE → MODEL → EVALUATE → TEST → EVOLVE. Each station has sensors (health metrics) and actuators (revision actions).

🎯

NomNom Eats Reference World

A ground-truth DGP (Data-Generating Process) with known causal effects — confounders, mediators, colliders, instruments, and negative controls. Every estimate can be checked against truth.

🧪

Causal CI/CD Pyramid

37 tests across 4 layers: unit (DGP sanity), integration (graph-compiled consistency), property (loop invariants), and regression (pinned numerical results).

📈

Tier-1 Real-Data Gallery

6 classic reproductions: Berkeley Simpson, LaLonde/NSW, Card-Krueger DiD, Oregon Lottery IV, Basque synthetic control, Sachs discovery — plus NHEFS real-world walkthrough.

📐

Math Bridge

6-level curriculum from basic probability to counterfactuals — each level ends by demonstrating which rung of Pearl's ladder it cannot reach.

Quick Start

# 1. Create the environment
conda env create -f environment.yml
conda activate causality-nd

# 2. Run the interactive Panel demo
panel serve panel_app/app.py --auto

# 3. Or open the Jupyter notebook
jupyter notebook notebooks/nomnom_endtoend/full_causal_workflow.ipynb

# 4. Run the test suite
python -m pytest causal_ci -q

Design Principles

P1Assumptions are first-class artifacts — versioned, inspectable DAG with explicit absent edges
P2The graph is the single source of truth — adjustment sets, test suites, and monitors are compiled from it
P3Every station has sensors and actuators — quantitative health signals drive revision actions
P4Refutation is continuous, not episodic — falsification checks run in CI and production
P5Ground truth where possible, benchmarks where not — methods graduate to real data after synthetic acceptance
P6Ladder discipline — every query tagged by Pearl's rung; rung-2/3 questions require recorded assumptions

The 9 UCL Stations

#StationCore QuestionKey Output
0FRAMEWhat decision does this inform?EstimandSpec
1ASSUMEWhat causal structure do we believe?AssumptionGraph
2IDENTIFYIs the effect computable from observables?IdentificationProof
3DATADo the data support the identification?DataContract + overlap
4FEATUREWhat enters — and what must not?FeatureSpec (excl. colliders)
5MODELHow do we estimate?EstimateBundle + CI
6EVALUATEHow wrong could we be?EvaluationReport (E-value)
7TESTDoes the machinery refute itself?CausalTestSuite
8EVOLVEIs the world still the one we modeled?EvolutionLog
Association is not causation — and the gap between them is not a philosophical footnote but an engineering problem.
Causal knowledge is fragmented (theory in books, estimators in libraries, assumptions in heads). This project makes assumptions into versioned, testable, monitorable artifacts — and builds the machinery to evolve them as the world changes.
