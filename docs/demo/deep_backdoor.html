Deep Dive: The Back-Door Criterion

Pearl (1995). Causal diagrams for empirical research. Biometrika.

1. The Problem

We have a causal DAG with treatment T and outcome Y. There are causal paths (T → ... → Y) and non-causal paths (paths with an arrow into T, called back-door paths). We need to block all back-door paths while keeping all causal paths open. The back-door criterion tells us exactly which variables to adjust for.

2. The Criterion (Pearl 1995, Def. 3.3.1)

A set of variables Z satisfies the back-door criterion relative to (T, Y) if:

  1. No descendant of T is in Z. This ensures we don't block causal paths or open collider paths via mediators.
  2. Z d-separates T from Y in the back-door graph. The back-door graph is the original DAG with all edges out of T deleted. This ensures all non-causal (back-door) paths are blocked.

3. Graph Surgery — Step by Step

Step 1: Delete all edges out of T

Remove T→M, T→Y, T→S. This creates the back-door graph. Any remaining path between T and Y is a back-door path that must be blocked.

Step 2: Candidate search

Consider subsets of observed variables that are not descendants of T. In our NomNom DAG, this excludes M (mediator) and S (collider descendant). Candidates include: {W}, {rain}, {weekend}, {payday}, and their combinations.

Step 3: Test d-separation

For each candidate set Z, test whether T and Y are d-separated by Z in the back-door graph. The smallest set that achieves d-separation is the adjustment set.

Step 4: Result

The compiler finds Z = {W, payday, rain, weekend} — the smallest observed set that blocks all back-door paths. M (mediator) and S (collider) are correctly excluded.

4. Why NOT to Adjust for Everything

If you adjust for...What goes wrong
M (mediator)Blocks the causal path T→M→Y. The estimate becomes the direct effect, not the total effect. Over-adjustment bias.
S (collider)Opens a spurious path T→S←Y. Creates association where none existed. Berkson's bias.
Z (instrument)May amplify bias (bias amplification). Z affects T but has no confounding role; controlling for it can increase the bias from residual confounding.
EverythingThe classic error: "control for everything you can measure." This guarantees you'll adjust for mediators (bias downward) AND colliders (bias in unpredictable directions).

5. d-Separation — The Graphical Test

A path between X and Y is blocked by a set Z if:

  • The path contains a chain (A→B→C) or a fork (A←B→C), and the middle node B is in Z.
  • The path contains a collider (A→B←C), and neither B nor any descendant of B is in Z.

X and Y are d-separated by Z if Z blocks every path between them.

Key insight: Conditioning on a chain/fork node blocks the flow of association. Conditioning on a collider node opens the flow of association. This is why "adjust for everything" fails — you can't tell from the data alone which nodes are chains/forks vs. colliders. You need the DAG.
