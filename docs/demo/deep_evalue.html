Deep Dive: The E-value

VanderWeele & Ding (2017). Sensitivity Analysis in Observational Research: Introducing the E-value. Annals of Internal Medicine.

1. The Problem It Solves

Every observational causal estimate rests on the assumption of no unmeasured confounding — that we have measured and adjusted for all common causes of treatment and outcome. But this assumption is untestable from the data alone. We need a way to answer: "How strong would an unmeasured confounder need to be to explain away our result?"

The E-value provides a quantitative, standardized answer — without requiring the analyst to specify the exact nature of the hypothetical confounder.

2. First Principles

2.1 The Risk Ratio

Start with the observed association between treatment (T) and outcome (Y), expressed as a risk ratio:

If RR > 1, the treatment is associated with higher outcome probability (positive association). If RR < 1, it's associated with lower probability (protective). For the E-value computation, we use the observed RR (or its inverse if RR < 1, to ensure RR ≥ 1).

2.2 The Key Question

Suppose an unmeasured confounder U exists. For U to fully explain away the observed RR, it would need to be associated with both:

  1. The treatment T, with risk ratio RRTU
  2. The outcome Y, with risk ratio RRUY

Both associations are conditional on the measured covariates X.

5. The CI-Bound E-value

For a more conservative assessment, compute the E-value using the confidence interval bound closest to the null instead of the point estimate. This accounts for statistical uncertainty: even if the true effect is near the lower CI bound, the E-value tells us how robust that smaller effect would be.
