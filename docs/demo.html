Glossary

ATE = E[Y(1)-Y(0)]
do(T=1) — Graph surgery: set T=1, cut incoming arrows
Y(1),Y(0) — Potential outcomes
SUTVA — No interference, one treatment version
AIPW — Augmented IPW (doubly robust)
DML — Double/debiased ML
E-value — Min confounder strength to explain away effect
SMD — Standardized Mean Difference
Confounder — Common cause (U: hunger)
Mediator — On T→Y path (M: app-open)
Collider — Common effect (S: engagement)
Instrument — Only affects T (Z: jitter)
Negative control — Shares U, no T effect (NC: battery)
