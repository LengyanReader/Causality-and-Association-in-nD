📖 Glossary

ATE — E[Y(1)-Y(0)]
SUTVA — Stable Unit Treatment Value Assumption: no interference, one treatment version
DAG — Directed Acyclic Graph (causal diagram)
SCM — Structural Causal Model
AIPW — Augmented IPW (doubly robust)
DML — Double/Debiased ML (Chernozhukov et al. 2018)
E-value — Min unmeasured confounder strength to explain away effect
SMD — Standardized Mean Difference (<0.1 = balanced)
Confounder — Common cause of T and Y (U: hunger)
Mediator — On T→Y path, don't adjust (M: app-open)
Collider — Common effect, NEVER adjust (S: engagement)
Instrument — Affects T only, no direct Y path (Z: jitter)
Negative control — Shares confounders, no T effect (NC: battery)
do(T=1) — Graph surgery: set T=1, cut incoming arrows
Y(1), Y(0) — Potential outcomes: what WOULD happen
Back-door — Block non-causal paths by conditioning
